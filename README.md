# Loop — Casa de inovação em IA

Site institucional da **Loop**, reposicionada como casa de inovação em IA com duas pontas:

- **Loop** — consultoria de implementação de IA em empresas. Diagnostica gargalos e entrega IA que funciona: automações, painéis, integrações e agentes operando dentro da operação. Visual clean e sóbrio (base atual da Loop + inspiração BRQ).
- **Loop Studio** — braço de criação: desenvolve produtos e soluções digitais 360° (pesquisa, UX/UI, service design, produto). Visual contrastante e criativo.

## Stack

Site estático, sem framework: **HTML + CSS + JavaScript** puro. Fácil de versionar e de fazer deploy (Hostinger/Vercel).

```
loop-website/
├── index.html            # página única (long-scroll com âncoras)
├── assets/
│   ├── css/styles.css     # design system + estilos
│   ├── js/main.js         # menu mobile, scroll-reveal, count-up
│   └── img/               # logos, og image, favicon
└── README.md
```

## Rodar localmente

Qualquer servidor estático serve:

```bash
python3 -m http.server 8000
# abre http://localhost:8000
```
